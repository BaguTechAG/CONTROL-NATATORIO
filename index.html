Control Natatorio

Natatorio Municipal Celina "Chela Gay"

Control Natatorio es una aplicación de escritorio para la gestión interna del natatorio: alumnos, pagos, asistencia y lista de espera.

La aplicación puede conectarse a una cuenta de Google del natatorio para crear planillas de Google Sheets con los listados de alumnos de cada grupo y turno, y compartirlas con los profesores correspondientes.

No es una aplicación pública: la usa únicamente el personal autorizado del natatorio.
